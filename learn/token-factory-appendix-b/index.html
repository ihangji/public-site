B 公式误读

Token 工厂拆解手册：从 GPU、推理服务到合同与现金流附录约 4 分钟更新于 2026-08-04

本册用到的七个公式集中列在这里，每个都带边界说明；后面是十个最常见的误读。公式的分母和时间窗口一旦换掉，结论就不再是同一个结论。

一，权重显存下界。权重内存（字节）约等于 参数量 乘 每参数位数 除以 8。这是下界，不含 KV 缓存、量化尺度、工作区、通信缓冲和运行时保留。

二，请求完成时间。端到端时间约等于 首字延迟 加（输出 token 数 减 1）乘 出字间隔。第一个输出 token 已包含在首字延迟里；不同监控系统对起止点定义可能不同，对比前先对齐口径。

三，有效吞吐。有效吞吐等于 测量窗口内成功且可计费的 token 除以 窗口时长。失败、取消、重试和不计费 token 是否进入分子必须明确。

四，可售利用率。可售利用率等于 实际可计费容量 除以 同期满足服务目标的可用容量。分母不是理论峰值，也不是 GPU 开机时间。

五，单位完全成本。单位成本等于（同期设备与资金 加 机房电力网络 加 软件运维 加 故障闲置 加 渠道与结算）除以 同期可计费 token。分子统一币种和周期，分母区分输入、缓存输入和输出。

六，毛利与边际贡献。毛利等于 收入 减 与交付直接相关的成本；边际贡献等于 收入 减 随业务量变化的可避免成本。边际贡献回答业务量增减时能留下多少，毛利受会计归类影响，比较前先统一口径。

七，可用性允许停机。允许停机时间等于 观察窗口 乘（1 减 可用性目标）。还要定义计划维护、上游故障和部分降级是否计入。
