26.1 分母纪律

推理业务最危险的财务错觉，是用理论峰值 token 做分母、用一个公开 API 价格做收入、再从中减去卡时成本。这样得到的数字既没有负载，也没有服务目标、闲置、故障、运维和资金成本。单位经济先定义多少 token 可售、可计费并最终回款，再讨论卡价。

把月度可计费量记作 B，它由四个变量连乘：B 等于 Qmax 乘 A 乘 U 乘 E。Qmax 不是硬件规格，而是在指定模型、精度、硬件、长度分布、并发、延迟约束下实测的月度合格产能；A 是服务就绪率；U 是真实付费需求对就绪容量的利用率；E 是生产环境相对基准的有效效率。四个变量分别解决四种混淆：峰值与生产、通电与就绪、就绪与有需求、实验配置与真实流量。高 GPU 利用率也不必然提高 B：接近满载时排队和尾延迟上升，更多请求超出服务目标，商业目标应是可计费的有效吞吐，不是单点的 GPU 忙碌度。核

26.2 成本分摊

固定或准固定的月成本包括：GPU 租金或折旧、机房托管、电力、网络、存储、软件许可、运维人力、资金成本和备件。变量成本包括随量的推理开销、出口流量、支付手续费、模型分成和预期服务信用。单位直接成本等于固定成本加变量成本，除以可计费量 B。这个公式最重要的纪律是防止重复计入：云卡时价已经包含设备、机房、电力与底层运维的，不能再加一遍；设备自有的，则要按选定口径考虑折旧、资本成本、备件和残值。单位成本还要标明口径：现金口径、直接成本、毛利口径还是完全成本。

26.3 收入构成

收入侧沿用第 25.1 节的多维计量：输入、输出、缓存、请求、工具、保留和服务费分开算。公开价格页可以用来解释结构，不能替代企业协商价、最低消费或返利。混合售价由输入输出比例、缓存命中、批处理折扣、模型、区域和客户阶梯共同决定。

26.5 交叉判断

serverless 与专用端点的选择有一个交叉点：客户用 serverless 的成本随用量线性增长，专用端点则以保留固定费为主。简化后，交叉量约等于固定费除以（serverless 单价减专用端点变量成本）。只有当交叉量不超过专用端点在服务目标下的真实容量、且流量足够稳定时，固定容量才可能更便宜；月总量很高但集中在短峰的客户，专用端点仍要为峰值留冗余。抢占式低价卡同理：目录价的直接效果是卡时便宜，间接代价是中断、迁移、恢复和额外冗余，研究里的成本改善只适用于其实验负载。核

26.6 毛差利润

毛差不是利润。至少要区分四层。

  • 边际贡献　收入减去随量可避免的成本，回答每多做一单留下多少
  • 毛利　取决于营业成本怎样归类
  • 营业利润　再扣技术基础设施、研发、销售与管理
  • 净利润与现金流　还受折旧、利息、税、资本开支、租赁和营运资金影响

CoreWeave 的年报同时披露营业成本、技术与基础设施、折旧、利息费用与净亏损，核个案不代表行业比例，但足以证明 token 收入减 GPU 直接成本不能叫净利润。五个最敏感的变量按序排：需求利用率、服务目标内的合格产能、混合售价、固定承诺（租赁、最低采购、人员）、客户集中度。降价的直接效果是收入减少，间接反馈是需求上升推高排队、有效吞吐下降、为守目标增加冗余、固定成本再次上升，单位经济是价格、负载和系统行为组成的反馈模型，不是一张静态表。

追问分母用的是峰值还是服务目标内的实测产能；打平需要的利用率是多少；哪个变量动一档整个模型就翻转。
